# Third-party assets

Several assets used in the original Unity project were obtained from external Unity packages or other external sources.

These files are retained in the local historical reconstruction of the project but are intentionally excluded from the public repository because redistribution rights have not been verified.

## Visual assets excluded

The local project contains assets from folders including:

- ADG_Textures
- Classic Acoustic Guitar
- Floor materials pack
- InstrumentsHD_vol1
- JJ_InteriorDoorPack_V1
- LowPolyAfricanInstruments
- Procedural_Materials
- Rockstar Asset Pack
- SampleScenes
- Shapes2D
- Standard Assets

Some of these assets are required for the recovered scenes to display exactly as in the original experiment.

## Audio excluded

The original LinearMaze scene uses four audio files:

- Guitar.mp3
- Bongos.mp3
- cymbal jazz.mp3
- Xilofon.mp3

The provenance and redistribution licences of these historical audio files have not yet been established, so they are not included in the public repository.

`Xilofon.mp3` is the renamed copy of the historical xylophone sound file used for the visual marimba stimulus.

## Reproducibility

The Unity scenes preserve the structure, object placement, configuration, and references of the recovered paradigm. A fully functional reconstruction requires replacement or legally obtained copies of the excluded third-party assets.

The prerecorded audiovisual stimulus presented during the EEG experiment should be regarded as the definitive experimental stimulus, particularly for temporal analyses.
